# Manual do Programador

Um guia completo do zero ao avançado para aspirantes a desenvolvedor, estruturado por módulos e com foco na linguagem **Java**. Este repositório foi criado para ser o roteiro definitivo de quem deseja aprender a programar com uma base sólida, entendendo não apenas o "como", mas o "porquê" de cada tecnologia.
